# Past Campaigns

The memory of your Company OS. One file per finished campaign: who you emailed, what you said, and what happened.

It starts empty. Run the `close-campaign` skill when a campaign ends and it writes the file here, then proposes what to change in your ICP, rules and skills.

Before writing a new campaign, agents check this folder for what worked with the same audience.

File names: `YYYY-MM-DD-short-name.md`
